# Game Hub
Welcome to **Game Hub** — a fast, browser-based portal hosted on GitHub Pages so you and your friends can launch web games and jump straight into links without heavy downloads.

## What's Inside
- **Quick Launcher:** Tap to open supported web apps and browser games fast.
- **Mobile & Desktop Friendly:** Built to run cleanly in modern browsers on phones, tablets, and computers.
- **Always Evolving:** New browser games, tweaks, and links can be added over time as the hub grows.

## How to Use It
1. Open the live GitHub Pages link for **Game Hub**.
2. Pick a tile or link from the hub to launch it in your browser.
3. Bookmark the page if you want quick access later.

## Heads Up for Friends & Players
- **Network & Device Rules:** Some links, embeds, or sites may behave differently depending on the browser, device, or network (such as school or public Wi-Fi) you're using. Please follow your school and device rules.
- **Original & Permitted Content Only:** This hub is meant for original browser games and links that are allowed to be shared — no pirated or unauthorized copyrighted game files.
- **Feedback & Ideas:** Got an original web game idea, bug report, or suggestion for the hub? Let me know so we can test and improve it!

## About This Project
Built and published on GitHub Pages (`munirnjm-web/game-hub`) as a fun project to share with friends and keep learning web development.
